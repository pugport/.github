**One for all agents.** Your AI subscriptions and accounts in one chat: PugPort sends each task to an account with usage to spare, picks the model for the job, and hands the work off when an account hits its usage limit.

**[pugport.com](https://pugport.com)** · **[Download](https://pugport.com/#download)** · **[Dev log](https://pugport.dev)** · **[Community](https://pugport.org)** · **[Discord](https://discord.gg/2GsqpfHy55)**

## Repositories

- **[pugport](https://github.com/pugport/pugport)**: the desktop app for Windows and Apple silicon Macs. TypeScript, React and Electron, Apache-2.0. It runs the official Claude Code, Codex, Grok and Cursor CLIs you already use, routes by real usage limits, and hands half-finished work to the next agent with a checked handoff note.

## Related

- **[Task Router](https://github.com/Waytrine/task-router)**: the fine-tuned 322M classifier that reads every PugPort message and decides its type, difficulty and tools in one pass. Weights on [Hugging Face](https://huggingface.co/Waytrine/task-router).
